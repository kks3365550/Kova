## Requirements (사용자 결정)
- 제품화는 **공개 유지가 목표** → 비공개 전환(C안) 불가. A(회전) + B(이력 정리) 방향
- 오프사이트 SSD 구매는 안 함 (비용). 기존 `\\품관김기수\k12백업` 활용 유지
- WORM 은 검증된 사실만 문서화 (주장 금지)
- 제품화는 묻지 말고 끝까지 진행 (승인 없이 커밋·푸시 수행함)

## Decisions
- 키 회전 없이 이력 정리만 하면 안심만 생긴다 → **회전 → 정리 순서 고정**
- CI 게이트는 추적 파일만 검사. 이력 전체를 게이트에 넣으면 기존 31건 때문에
  영구히 빨갛게 되고, 빨간 CI 는 아무도 안 본다
- `verify_update` 의 명시적 `pub_key_path` 인자는 기존 동작 유지 (테스트 격리).
  키링 모드는 명시 목록 → 자동 탐색(`keys/*.pub`) 순서
- 한국어 출력 도구는 stdout UTF-8 재설정 + CI `PYTHONIOENCODING` 명시 (이중 안전).
  같은 cp1252 실패를 두 번 냈으므로 패턴으로 고정
