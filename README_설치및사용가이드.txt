================================================================================
  [백업 매니저] 새 데스크탑 PC 설치 및 사용 가이드
================================================================================

본 폴더([백업시스템_설치용])는 다른 새로운 데스크탑 PC에 백업 시스템을
그대로 복사하여 즉시 사용할 수 있도록 패키징된 배포용 폴더입니다.

--------------------------------------------------------------------------------
1단계 : 새 데스크탑으로 폴더 복사하기
--------------------------------------------------------------------------------
1. 이 [백업시스템_설치용] 폴더를 USB 메모리나 외장하드, 클라우드 드라이브 등을
   이용하여 새 데스크탑 PC의 원하는 위치로 통째로 복사합니다.
   (추천 위치: D:\백업시스템 또는 C:\백업시스템)

--------------------------------------------------------------------------------
2단계 : 원클릭 환경 설치 (최초 1회만 실행)
--------------------------------------------------------------------------------
1. 폴더 안의 [ 1_원클릭_환경설치(최초1회).bat ] 파일을 더블 클릭합니다.
2. 파이썬(Python)이 컴퓨터에 설치되어 있다면:
   - 가상환경 및 필수 라이브러리가 자동으로 세팅되고,
   - 윈도우 바탕화면에 [백업시스템 대시보드] 바로가기 아이콘이 자동 생성됩니다!
3. 만약 파이썬이 설치되어 있지 않다면:
   - 파이썬 다운로드 창이 자동으로 열립니다.
   - [중요!] 파이썬 설치 파일 실행 시 첫 화면 하단에 있는
     [Add python.exe to PATH] (환경변수 추가)에 꼭 체크하고 설치해주세요.
   - 파이썬 설치 완료 후 다시 [ 1_원클릭_환경설치(최초1회).bat ]을 실행하시면 됩니다.

--------------------------------------------------------------------------------
3단계 : 백업 시스템 실행 및 사용하기
--------------------------------------------------------------------------------
1. 바탕화면에 생성된 [백업시스템 대시보드] 아이콘을 더블클릭하거나,
   폴더 내의 [ 2_백업시스템_실행.bat ]을 실행합니다.
2. 인터넷 브라우저에 모던 웹 대시보드가 자동으로 열립니다.
   (기본 주소: http://127.0.0.1:8765)
3. 대시보드의 [프로필 관리] 메뉴에서:
   - 백업할 대상 폴더(예: 내 문서, 바탕화면, 작업 폴더 등)를 선택하고,
   - 백업본을 저장할 외장하드나 D: 드라이브 폴더를 지정합니다.
4. [백업 시작] 버튼을 누르면 첫 전체 백업이 수행되며,
   이후에는 수정/추가된 파일만 초고속 증분 백업됩니다.
5. 상단의 [스케줄러 활성화]를 켜두시면 정해진 주기마다 자동으로 백그라운드 백업됩니다.

--------------------------------------------------------------------------------
4단계 : 백업 시스템 종료하기
--------------------------------------------------------------------------------
- 백업 시스템은 백그라운드에서 조용히 동작합니다.
- 프로그램을 완전히 종료하고 싶을 때는 [ 3_백업시스템_종료.bat ]을 더블클릭하시면 됩니다.
