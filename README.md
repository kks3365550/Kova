# Kova2

Windows용 백업·복구 프로그램입니다. Rust로 만들었고, 파일 백업과 디스크 통째 이미지 백업을 한 프로그램에서 쓸 수 있습니다.

## 주요 기능

- **파일 백업**: 바뀐 부분만 저장하고(중복 제거, FastCDC), 압축(Zstd)과 무결성 검사(BLAKE3)를 합니다. NTFS 변경 기록(USN 저널)으로 빠르게 훑습니다.
- **쓰는 중인 파일도 백업**: VSS 스냅샷으로 잠긴 파일을 같은 시점으로 읽습니다.
- **디스크 통째 백업**: 드라이브를 이미지 파일(`.qblk`)로 저장하고, 검사하거나 꺼내서 `.img`로 풀 수 있습니다. 다른 프로그램의 `.img`/`.raw`/`.bin`/`.vhd`를 `.qblk`로 바꾸는 기능도 있습니다.
- **랜섬웨어 보호**: 백업 파일을 읽기 전용으로 잠그고, 삭제는 보존 정책 같은 승인된 경로로만 합니다.
- **암호화**: 저장소별로 백업을 암호화할 수 있습니다.
- **보존 정책**: 개수·기간·주간·월간 단위로 옛 백업을 자동 정리합니다.
- **오프사이트 복제**: 백업 직후 다른 폴더나 네트워크 공유로 한 부 더 보관합니다.
- **예약 백업과 복구**: 자동 실행, 실패 시 재시도, 백업 목록에서 파일을 골라 되돌리기, 저장소 검증.
- **안전한 업데이트**: 서명이 확인된 패키지만 설치합니다.
- **앱 잠금**: 마스터 비밀번호로 설정 변경과 삭제를 막을 수 있습니다.

## 설치

[Releases](../../releases)의 최신 `Kova2_Setup_vX.Y.Z.exe`를 받아 설치합니다. 관리자 권한이 필요하고, 백업은 Windows 서비스(`KovaSvc`)가 실행합니다. 받은 파일은 같은 릴리즈의 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 구성

[`kova2/`](kova2/) 아래의 Cargo 워크스페이스입니다.

| 크레이트 | 역할 |
|---|---|
| `kova-app` | 화면(Slint) |
| `kova-service` | 백업을 실행하는 서비스 |
| `kova-core` | 설정, 보존, 암호화, 랜섬웨어 보호, 업데이트, VSS 등 공통 기능 |
| `kova-engine` | 파일 백업 엔진 |
| `kova-image` | 디스크 이미지(`.qblk`) |
| `kova-ipc` | 앱과 서비스 사이 통신 |

## 빌드와 검사

Windows와 Rust가 필요합니다.

```
cd kova2
cargo build --release
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

푸시할 때 GitHub Actions가 서식, clippy, 빌드, 테스트를 같은 순서로 검사합니다.
