# Kova2 v3.15.4 버그 전수조사 (2026-11-21, 읽기 전용, 코드 판독 기준)

[직접 재확인] 표시 = 보고 후 리드가 코드를 다시 읽어 확인. 나머지는 조사 결과 그대로(미재현).

## 데이터 손실·복구 불가
1. [직접 재확인] 오프사이트(폴더·구글 드라이브) 복제가 crypto.json(암호화 표식)을 복사하지 않음: offsite.rs:118-192, gdrive.rs:820-960. 암호화 저장소는 오프사이트만으로 복구 불가.
2. [직접 재확인] 원위치 복원이 대상 파일을 먼저 File::create로 비운 뒤 검증: ops.rs:845. 실패 시 원본이 잘림.
3. [직접 재확인] 스냅샷 ID가 초 단위, 덮어쓰기 검사 없음: ops.rs:168-171, storage.rs:420-427. 공유 저장소의 두 프로파일이 1초 안에 연달아 돌면 앞 스냅샷 소실.
4. chunker.rs:27-49 해시 계산과 복사 사이 파일 변경 시 해시 불일치 블롭이 저장되고 이후 중복제거로 전파(VSS 실패 시).
5. chunker.rs:42-66 파일 전체를 메모리에 복사 → 대용량 파일에서 OOM·서비스 abort.
6. config.rs 읽기 실패를 빈 목록으로 처리 후 upsert가 덮어써 프로파일 전부 소실 가능; 잠금 없는 읽기-수정-쓰기 경합(config.rs:171-223, alerts.rs).
7. 구형 매니페스트 blob_id 재사용(ops.rs:242-250, 조건부), 증분 키가 원본 경로를 쓰지 않아 원본 목록 변경 시 엉뚱한 청크 재사용(ops.rs:253-297).
8. offsite.rs:143-161 스냅샷 하나가 깨지면 이후 복제 전체 중단; gdrive.rs:864-938 실패가 eprintln만 남고 성공 표시.

## 보안
9. [직접 재확인] 파이프 권한 AU, 호출자 확인 없음, delsnap 처리(lib.rs:929) → 일반 사용자 권한 프로그램이 스냅샷 삭제·image:C 이미지 생성(SYSTEM) 요청 가능(ipc lib.rs:81-84, service lib.rs:706-723, 920-947).
10. 구글 토큰·저장소 키 DPAPI LOCAL_MACHINE, config 폴더 Users 읽기(실측 icacls): repocrypto.rs:96-106, gdrive.rs:87.
11. 웹훅 URL(비밀 토큰)이 로그·진단 ZIP에 평문 노출 가능(notify.rs:42, diag.rs:113).
12. fetch.rs:105-121 서명이 버전에 묶이지 않아 다운그레이드 가능.

15. [직접 재확인] 전체 검색 '원래 자리 복원'이 확인·잠금 검사 없이 즉시 덮어씀(main.slint:1620, main.rs:2943).
16. [직접 재확인] 검증 "오류 있음" 스냅샷이 초록 "무결성 검증"으로 표시(main.slint:1661-1673).
17. 설정 탭0 주기·보관·저장소 칸은 저장되지 않음(main.slint:2058-2107). 첫 실행 스마트 백업 결과 문구 미표시(main.slint:1162). 웹훅·키복원 결과 미표시(main.slint:2264,2296). send()가 IPC 오류를 버림(main.rs:1726).
18. 잠금 우회: 볼륨 복원·save_profile·offsite 저장·run_gc 등에 app_locked() 검사 없음(main.rs:2414, 3083 등).
19. UI 스레드 블로킹(JobFinished 갱신, 드라이브 연결 해제, 찾아보기 대화상자), History::open이 존재하지 않는 저장소 폴더·DB를 만들고 2초마다 integrity_check(main.rs:505-516, history.rs:97).
20. 알림/프로파일 파일이 서비스 재작성 후 Users 읽기 전용이 되어 앱이 "모두 읽음"·오프사이트 설정을 저장 못함(config.rs:162-169, alerts.rs:34-44; 실측 ACL).
